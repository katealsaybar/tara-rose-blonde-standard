# The Blonde Standard

Standalone landing page for Tara Rose Salons' blonde campaign, UAE.

One page, no build step: `index.html` plus `css/`, `js/` and `assets/`.
`css/trs-core.css` and `css/trs-blocks.css` are the shared Tara Rose design
system and are never edited here; everything page-specific lives in
`css/blonde-standard.css`.

The page sells a plan, not a package: the three-touchpoint blonde rhythm, the
three lanes (Soft · Signature · Transformation), and a free consultation as the
only call to action. It carries no prices by design.

Decisions, resolutions and open items: `docs/BUILD-NOTES.md`.

Ships with `noindex,nofollow` until the launch gates clear.
